Trust needs proof.

I'm Felix. For transparency, I'm 20, and I build and support Roma myself. The current public build asks for broad macOS access and is not notarized. Below are my recommendation and the evidence for this build.

Current v1.95 recommendation

I do not recommend v1.95 for your main Mac yet.

The download is an ad hoc signed Debug build. Apple has not notarized it, so macOS may block its first launch. Do not disable Gatekeeper. If you are not comfortable choosing Open Anyway, wait. Treat v1.95 as an early evaluation build, not a production-ready release.

Lower-risk ways to evaluate it

Start with the no-microphone browser preview. To evaluate the Mac app, use a secondary Mac without sensitive data. Choose a local transcription model, set Settings > Rolling Buffer > Buffer Preload to Off, and turn AI Enhancement off. Do not grant Screen Recording or Automation unless you need those features.

Roma still reads the clipboard locally when a recording starts. Quitting Roma stops microphone capture.

What Roma reads and sends

Microphone before Shift

With microphone permission, v1.95 listens while its rolling buffer is active. Its default buffer holds the latest three seconds of audio and replaces older audio as you speak.

With a cloud streaming model, v1.95 can start sending audio when its local speech detector fires, before you press Shift. The rolling buffer and audio that follows may reach that provider. Set Buffer Preload to Off before using a cloud model to stop this pre-Shift sending.

Cloud providers

Local transcription keeps audio on your Mac. Cloud transcription sends audio directly to the provider you choose. AI Enhancement sends the provider your transcript, polishing instructions, custom vocabulary, and selected text Roma can read. With Clipboard Context on, it sends clipboard text. With Screen Context on, it sends the app name, window title, and recognized window text. The provider's retention and training rules apply.

Clipboard and visible windows

Roma reads your clipboard whenever you start a recording, even if Clipboard Context is off. With Screen Recording permission, it also captures and reads a visible window, even if Screen Context is off. It tries the frontmost window first, but v1.95 can fall back to another visible non-Roma window. Those switches only control what AI Enhancement receives. Revoke Screen Recording to stop window capture.

History and provider keys

Local history can retain audio, transcripts, polished text, and the messages sent for polishing. Cleanup is off by default. History cleanup can remove old records and their audio. Audio cleanup removes old audio but keeps the text record. Deleting local history cannot delete data a provider retained.

The public v1.95 download stores provider API keys in Roma's local settings, not macOS Keychain. Use a separate key you can revoke and set a provider spending limit when available.

Automatic connections

This website uses Vercel Web Analytics. v1.95 checks beingpax.github.io for updates and announcements. The Mac app does not automatically send usage or crash reports to me. I learn about a failure only when someone reports it.

Why Roma asks for broad access

Here is how v1.95 uses each permission.

Microphone
Required for dictation. Buffers and records speech.
Input Monitoring
Required for the global shortcut. Detects the keys you chose.
Accessibility
Works with Input Monitoring for shortcuts, inserts text, and can read selected or nearby text.
Screen Recording
Optional. Captures a visible window for on-device text recognition. v1.95 can fall back from the frontmost window to another visible non-Roma window.
Automation
Optional. Lets Roma paste through AppleScript and control supported browsers for Power Modes.

Revoke any permission in macOS System Settings. The related feature will stop working.

If Roma causes a problem

You should not become Roma's QA team.

Reports and retesting are optional. One message is enough to start. I own the work of reproducing the problem.

Start with a description. Do not send a raw recording, transcript, API key, or unredacted screenshot. If I need evidence, I will ask for the smallest useful piece and explain how to redact it. I will tell you what I can reproduce. When a fix ships, I will name it in the release notes.
