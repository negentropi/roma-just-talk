The existing dependency cache avoids needless new Whisper builds. Freeze actual source/framework once; never pull between lanes. Schema JSON retains defaults and meaningful array order; unexpected differences fail for diagnosis. Source inspection found unconditional app startup pre-roll attempts, so the probe makes no microphone-inactivity claim. It requests no dictation or recognition and tests no audio/provider result.

This establishes local stores created by the predecessor source with the recorded current toolchain. It does not establish a shipped historical binary/compiler, arbitrary customer databases, new-field migration or CloudKit synchronization. The later feature must write its new metadata, exit, and verify it in another process before acceptance.
