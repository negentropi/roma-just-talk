# Scoped local compiler and process checks

`probe.receipt.json` binds `probe.swift` and its stdout to the candidate service source. The tiny harness executes the exact private process owner with the real Core error enum; it supplies only app logging metadata. It checks the parent's SIGCHLD disposition before/after an actual Foundation Process and exercises large I/O, early exit and cancellation. It does not independently identify the canceled child PID or build the Core module/app.

`macro-shapes.receipt.json` binds the four async throws expressions and six optional/Boolean requirements from the new test file. The installed Swift Testing plugin expands them under Swift language 5 and 6 with warnings as errors. Typed closures replace actual service/fixture bodies; this is compiler-only evidence.

Original temporary paths in the receipts identify where those checks ran. The copied sources/logs are alongside the receipts here. Matched service execution, app-host compatibility and full gates remain pending in the [lifetime plan](../../local-cli-lifetime-plan.md).
